# data/submissions/ — music submitted for chart consideration

One JSON file per submission, from `submit-music.html`.

```json
{
  "artist": "", "track_title": "", "release_date": "YYYY-MM-DD",
  "label_or_independent": "", "isrc": "",
  "streaming_links": "", "radio_single": "Yes",
  "contact_email": "", "press_photo": "", "bio": "",
  "chart": "gospel",
  "submitted_at": "2026-09-11T14:02:00Z"
}
```

Submissions feed the **release and submission activity** input, which is 15% of
a chart position. Submitting does not guarantee charting, and the auto-reply
says so plainly.

**`contact_email` is never published.** It exists so we can reply.
